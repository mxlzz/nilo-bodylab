# BodyLab — Programa Nilo

**Diseño aprobado 2026-11-25; E0 abierta. No existe organismo validado.**

Investigamos la corporalidad física y fisiológica como fundamento de la existencia autónoma: qué organización material mínima permite que una entidad situada tenga condiciones propias de existencia, necesidades intrínsecas y capacidades dependientes de su estado corporal.

Fundamentos comunes y primer cuerpo sencillo de morfología fija; después de validar G3, dos recorridos: P (principal, plan corporal parcialmente determinado con desarrollo individual y plasticidad) y X (exploratorio, morfogénesis abierta, no bloqueante). El cuerpo fijo permanece como control. No hay especie, anatomía, escala, lenguaje ni motor seleccionados.
